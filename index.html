Kya mujhe pehle se Python aana chahiye?
Bilkul nahi. Beginner track print se shuru hota hai, aur level 21 tak koi function nahi aata. Jise pehle se aata hai wo Medium ya Advanced se shuru kar sakta hai.

      
Kuch install karna padega?
Nahi. Python browser me hi chalta hai. Pehli baar page thoda sa download karta hai, uske baad tumhara code yahi chalta hai.

      
Mera progress kahan save hota hai?
Server pe, tumhare account me. Browser saaf kar do ya doosre browser me login kar lo, points aur solved levels wahi ke wahi milenge.

      
Kya ye sach me free hai?
Haan. Ye tumhare apne computer pe chalta hai. Sirf dost wala chatbot ek Claude API key maangta hai, aur wo key server pe rehti hai, page me kabhi nahi jati.

      
Kitna time lagega?
